# Hollis 0.3.3 — maintenance release

Hollis 0.3.3 replaces the withdrawn 0.3.2 release with a fresh build from the
current source. Runtime behavior, installed Shortcuts, configuration and
conversation storage are unchanged. No migration or bridge reimport is required.

It retains the clearer `request_declined` and `shortcut_failed` diagnostics and
bounded `auto` fallback described in the [0.3.2 changes](v0.3.2.md). The historical
[44-call validation](v0.3.2-validation.json) remains evidence for that earlier
build; it is not relabelled as a new live test of 0.3.3.

## Verification and installation

This release runs formatting, vet, Go tests and race checks, plus bridge and
review-boundary regressions before building both macOS binaries. It publishes
fresh SHA-256 checksums, an SPDX SBOM and GitHub build provenance tied to the
0.3.3 source tag. Earlier binaries and attestations are not reused or relabelled.

Use the [verified installation instructions](../../README.md#install-verified).
Existing installed versions continue to work; new installations should use
0.3.3. The five bridges and platform requirements remain unchanged.

The companion plugin keeps its separate version, 0.1.0. Its package is built
only after this runtime's published assets and provenance are verified and its
version-and-hash lock is updated.

Fresh-account setup, first Apple consent and reliable pixel-guided image editing
remain unproven. This maintenance release makes no new capability claims.
