**Apple Cloud and Cloud Pro, explicitly selectable from your terminal.**

On macOS 27.0 build `26A428`, Apple’s `fm` CLI lists only its on-device system
model. Hollis offers both cloud choices through Shortcuts:

```sh
hollis respond --model cloud "Review this plan"
hollis respond --model cloud-pro "Review this plan"
```

This release also adds explicit native
`local` inference with genuine incremental text in the terminal, chat and both
API endpoints. Complete native responses expose Apple's measured token usage;
streaming usage is not claimed. The existing `on-device` and `auto` choices keep
their routing.

The text transport repair stages exact prompts in private temporary files before
calling Shortcuts. This prevents the reproduced code-shaped stdin corruption.
Cancellation also cleans staged files and child processes. Abrupt termination
such as SIGKILL or a power failure cannot guarantee cleanup. Production bridges
remain unchanged; a corrected transport does not guarantee a model will fulfil
or accept a coding request.

Native local needs Apple Silicon/macOS 27 and the matching precompiled helper.
Human terminal output streams by default; JSON/agent output remains complete.
Terminal control sequences cannot execute through the streaming display.
Oversized conversations fail clearly without silently dropping history.

Use the [native-local installation guide](https://github.com/kamenxrider/hollis/blob/v0.4.0/docs/native-local.md).
The companion plugin 0.2.0 will follow as a separate release.
The approved Hollis identity now appears in the product documentation. Private
research and brand working files are excluded from packages and source archives.

Apple may request consent during first use. Fresh-account onboarding has not
been qualified. Cloud and Cloud Pro remain subject to Apple’s usage limits.
