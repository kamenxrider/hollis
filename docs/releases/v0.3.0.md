# Hollis 0.3.0

Apple Cloud and Cloud Pro now fit into more of your workflow: read documents,
process a folder with resumable progress, send images through the local API,
and generate images from the terminal or a conversation.

## New

- **Document input:** `--prompt-file` for instructions and repeated `--file` for
  UTF-8 `.txt`/`.md` documents. Available on all four model tiers.
- **API image understanding:** inline PNG/JPEG input in Chat Completions and
  Responses, using Cloud, Cloud Pro or ChatGPT.
- **Folder processing:** plan a finite job, set a call budget, pace requests,
  and resume without repeating verified completed results.
- **Image generation:** save PNGs, select styles, crop/pad/resize locally, and
  generate explicitly within CLI chats and both API conversation formats.
  Reference images and replayed assistant images can guide a new generation.
- **One complete bridge bundle:** the four model shortcuts and the corrected
  image-generation shortcut are included in `hollis-bridges.zip`.

## Upgrade

Verify the binary and bridge archive using the [Quickstart](https://github.com/kamenxrider/hollis/blob/v0.3.0/README.md#quickstart).
Import all five shortcuts. If you already imported **Hollis Image - Reference
Input v2**, replace it with this release's copy: an explicit Decode → Get Images
connection fixes reference delivery inside the shortcut. Then run:

```bash
hollis config set image-bridge "Hollis Image - Reference Input v2"
hollis doctor
```

**API authentication is now required by default**, including on localhost.
Supply a private `--token-file` or `HOLLIS_API_TOKEN` containing at least 32 bytes.
`--no-auth` remains an explicit loopback-only opt-out. Restart running servers
after updating the binary or bridge configuration.

The release hardens image file handling, batch locks and macOS ACL checks,
terminal rendering, API capacity admission, test credentials and complete
artifact verification. The Poolside review workflow now sends a bounded diff
to a text-only client without a model command executor. These address all nine
recorded audit findings; the new GitHub review job has not yet run live.

## Image scope

Animation, Illustration, Sketch, Genmoji and Any Style returned images on the
tested macOS 27 build. **Photographs are not guaranteed. ChatGPT image generation
through Shortcuts is blocked on that build.** ChatGPT text and image understanding
are separate working routes. Sizes and aspect ratios are local post-processing;
references create variations rather than exact edits.

The bundled Shortcut returned files without per-image clicks on the authorized,
unlocked test Mac. Initial macOS permissions can require attention. Fresh-Mac
setup and locked/logged-out operation are not qualified. The visible native
Image Playground helper is not included.

## Verification and downloads

The development record includes 21 successful live document/API/batch requests,
multiple paced image-generation runs, and targeted reference-connection controls.
The assembled candidate passed five additional live image calls, including both
API conversation formats and a signed import from the actual release ZIP.
Local validation covers Go tests/race/vet, Python harness and packaging tests,
and builds for both Mac architectures. See [EVIDENCE.md](https://github.com/kamenxrider/hollis/blob/v0.3.0/EVIDENCE.md) for
what these tests establish and their limits.

Unsigned macOS binaries, the five-shortcut archive, SHA256SUMS and SPDX SBOM
are the release assets. Verify checksums and GitHub build attestations before
installing. No Developer ID signature or notarization is claimed. Apple
Intelligence requires compatible Apple silicon hardware; an Intel binary alone
does not make an Intel Mac eligible for Apple's models.
