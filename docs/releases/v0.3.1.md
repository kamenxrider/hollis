# Hollis 0.3.1

A small privacy and diagnostics update for image generation, with all 0.3.0
capabilities and the same complete five-shortcut bundle.

## Fixed

- Image-reference errors distinguish missing files, denied access and other
  read failures without repeating the local path. This covers direct image
  generation, explicit conversation references and previous image artifacts.
- Invalid references stop before an Apple request. Error classifications, exit
  codes, checksums, size limits and protections against symlinks and special
  files are preserved.
- Ordinary source builds report `dev` instead of the stale `0.2.0` default.
  Release binaries continue to report their exact version, now `0.3.1`.

## Upgrade

Download and verify the new binary using the
[Quickstart](https://github.com/kamenxrider/hollis/blob/v0.3.1/README.md#quickstart).
Existing configuration, conversations, credentials and bridge choices are
preserved. The five bridge files are unchanged from 0.3.0; existing 0.3.0
imports do not need replacement. Restart a running Hollis API server to use
the updated binary.

## Validation

Full Go tests, race tests and vet passed. Regression tests cover path-free
errors, zero generator calls on invalid references, existing file protections
and development/release version identities. Twelve actual CLI process checks
passed across direct/chat, human/agent and missing/denied/other failures.

Four serialized Apple calls through Claude and Codex passed with the local
0.3.1 build: two Cloud answers, an Illustration and a Sketch using the preceding
image as an explicit reference. Both hosts returned absolute image links.
These tests used an already-approved Mac account; fresh-account setup and fresh
Apple consent remain unproven. See the existing
[capability evidence and limits](https://github.com/kamenxrider/hollis/blob/v0.3.1/EVIDENCE.md).

## Assets

Both macOS binaries, `hollis-bridges.zip`, `SHA256SUMS` and the SPDX SBOM are
included. Verify checksums and GitHub build attestations before installing.
No Developer ID signature or notarization is claimed. Apple Intelligence still
requires compatible Apple silicon; the Intel binary does not add that support.

The agent plugin remains a separate, unpublished 0.1.0 package. This runtime
release supplies the verified assets needed for its next bundle.
