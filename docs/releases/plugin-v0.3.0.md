# Hollis plugin 0.3.0

**Not released; replaced by 0.4.0.** These were plans, not a published package.
There is no 0.3.0 archive to install.

The planned update targeted runtime 0.7.0, its matching native helper and nine
bridges. It described guided output, route diagnostics and capability checks,
with configuration and conversation preservation.

[Plugin 0.4.0](../../plugins/hollis/README.md) carries those plans forward.
It is not yet published: its checked-in lock still pins runtime 0.4.0.
Runtime 0.7.0 must be published, authenticated and pinned before the plugin
package can follow.

The latest published plugin is
[0.1.0](https://github.com/kamenxrider/hollis/releases/tag/plugin-v0.1.0),
which bundles runtime 0.3.3 without native local. Plugin 0.2.0 was withdrawn.

Runtime 0.7.0's database upgrade is separate from plugin publication; review
[database upgrades and recovery](../cli.md#database-upgrades-and-recovery)
before changing runtimes.
