# A neighbourhood repair cafe

We want a small website where residents book a free Saturday repair session.
Volunteers repair bicycles, lamps and small household objects. Our first event
has four volunteers, each available from 10:00 to 13:00. We plan 30-minute slots.

Proposed first version:
- A booking form asks for a name, email, item category and preferred time.
- The server inserts a booking and immediately sends a confirmation.
- The form displays available slots from a cached schedule refreshed every hour.
- Everyone can submit the form without an account.
- A volunteer dashboard lists bookings and can mark repairs completed.
- We retain bookings indefinitely to compare attendance across future events.

We want a calm, welcoming experience, minimal personal data, and a first event
that volunteers can actually manage. What should change before we build it?
