# Homebrew formula preparation

`hollis.rb.in` is a formula template, not a published tap formula. Render it
only from a locally downloaded release set whose source ref, full commit,
signer workflow and `--deny-self-hosted-runners` attestation have already been
verified independently. The preparation script checks local manifest, asset,
bundle, bridge and checksum agreement; that offline check is not provenance
authentication.

The selected release must include the reviewed sidecar; older published releases
do not gain this record retroactively. Set the variables below to the exact
independently authenticated tag ref and full source commit.

```sh
python3 scripts/release/verify_artifacts.py /path/to/verified-release \
  --source-ref "$HOLLIS_SOURCE_REF" \
  --source-commit "$HOLLIS_SOURCE_COMMIT"
python3 scripts/release/prepare_distribution.py /path/to/verified-release \
  --output /tmp/hollis.rb
```

This renders a local formula only. It does not write to a tap, install Homebrew,
change global package-manager state, or run inference. Do not treat a locally
built candidate or an offline fixture as published provenance.

The formula keeps `hollis`, `hollis-native`, the bridge archive and the bundle's
existing `manifest.json` in one versioned `libexec` directory. Public `bin`
entries are symlinks into that directory. Completion files are generated by
`hollis completion` during formula installation. Homebrew uninstall removes its
keg but does not remove Hollis chats or configuration.

Homebrew installation and formula execution have not been tested in this
preparation-only change. Any future real package-manager test must use an
isolated prefix; fresh-account onboarding and published-download verification
remain unverified.
