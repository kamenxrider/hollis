# Hollis plugin 0.2.0

**Release preparation: not yet published. Runtime 0.4.0 pins are pending.**

Adds installation and discovery for the explicit native-local route, alongside
Cloud, Cloud Pro, On-Device, ChatGPT and image generation through Shortcuts.
The matched runtime and precompiled helper are verified together; configuration,
bridges and conversations remain intact. Local model availability is distinct
from a successful inference call.

Plugin packaging must verify the published 0.4.0 runtime artifacts and provenance
before pinning them. An older lock is not proof that 0.4.0 has been packaged.
